# Ozin Web

Frontend de Ozin (Angular 21 + PrimeNG 21). Ver el [README principal](../README.md).

```bash
npm install
npm start         # http://localhost:4200 (proxy /api -> http://localhost:8080)
npm run test:ci
npm run e2e               # Requiere el backend en marcha
npm run check:licenses
npm run build
```
